### Описание проекта

Это простая консольная программа, которая реализует анимированный управляемый вертолёт в текстовом режиме DOS. Программа демонстрирует работу с прерываниями, обработку клавиш и базовую анимацию в реальном времени.

### Основные возможности

- Управление вертолётом с помощью клавиш стрелок
- Анимация лопастей вертолёта в реальном времени
- Графическое отображение в текстовом режиме
- Система прерываний для обработки ввода и таймера

### Технические детали

Программа использует следующие компоненты:

- Текстовый режим DOS (режим 80×25)
- Прерывание 09h для обработки клавиш
- Прерывание 1Ch для таймера
- Работа с видеопамятью

### Управление

При нажатии на стрелки вверх, вних, влево, вправо, вертолет двигается в соответствующих направлениях. Esc - выход из программы.

### Структура кода

Основные компоненты программы:

- keyhandler - обработчик клавиш
- timer - обработчик таймера для анимации
- printp - процедура вывода на экран
- init - инициализация прерываний

### Как запустить

Открыть исходник можно с помощью клавиши F4. Запуск самой программы происходит по команде copter.exe. Компиляция исходника и создание исполняемого файла осуществляется командами tasm copter.asm, tlink copter.obj /t
